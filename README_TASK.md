# Задача

Есть сайт https://elibrary.ru/ я хочу посредством инстумента типа playwright или его аналога иметь возможность вбивать в поисковик этого сайта запрос и получать информацию о выдаче сайта на мой запрос в виде 

"title": title,
"href": href,
"body": "body"
где title-название статьи, href-ссылка на текст или pdf статьи если есть, или doi если нет, body - abstract статьи если доступен

## Ожидаемый результат
- Вызов: должен быть возможен через API
- параметр --query задает запрос для поиска
- параметр --num указывает сколько ссылок на статьи из выдачи должно вернуться

## Ограничения
- Язык: Python 3.12
- Тест-покрытие >=90 % (pytest + coverage).
