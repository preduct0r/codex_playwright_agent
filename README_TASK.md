# Задача

Есть сайт https://elibrary.ru/ я хочу посредством инструмента типа Playwright или его аналога иметь возможность вбивать в поисковик этого сайта запрос и получать информацию о выдаче сайта на мой запрос в виде

"title": title,
"href": href,
"body": "body"
где title-название статьи, href-ссылка на текст или pdf статьи если есть, или doi если нет, body - abstract статьи если доступен

## Ожидаемый результат
- Вызов: должен быть возможен через API
- параметр --query задает запрос для поиска
- параметр --num указывает сколько ссылок на статьи из выдачи должно вернуться

## Ограничения
- Язык: Python 3.12
- Тест-покрытие >=90 % (pytest + coverage).

## Установка
1. Создайте виртуальное окружение для Python 3.12.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Для загрузки браузеров выполните:
   ```bash
   playwright install
   ```

## Использование
После установки зависимостей предполагается запуск будущего скрипта следующим образом:
```bash
python -m src.main --query "example" --num 5
```
Параметр `--query` задаёт поисковый запрос, `--num` определяет количество ссылок в ответе.

## Тестирование
Чтобы выполнить тесты с проверкой покрытия, запустите:
```bash
pytest --cov=src --cov=tests --cov-fail-under=90
```
